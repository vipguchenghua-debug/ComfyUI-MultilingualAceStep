# ComfyUI-MultilingualAceStep 🌍🎤

将中文、日文、韩文等多语言歌词自动转换为 ACE-Step 兼容格式（带 `[zh]` / `[ja]` / `[ko]` 罗马字），支持标准歌曲结构标签。

> 💡 无需手动查拼音！AI 歌曲生成从此支持多语言！

## 🎯 功能
- ✅ 中文 → `[zh]ni3 hao3`
- ✅ 日语 → `[ja]konnichiwa`
- ✅ 韩语 → `[ko]annyeonghaseyo`
- ✅ 支持 `[verse]`, `[chorus]`, `[bridge]` 结构
